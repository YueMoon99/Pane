# UI 设计与交互规范

> 项目工作代号：**Pane**
> 设计基线：macOS 26 Tahoe（Liquid Glass）／ 向下兼容 macOS 15 Sequoia
> 文档版本：v1.0

---

## 1. 设计原则

> **「看起来像系统的一部分，用起来比系统更顺手。」**

| # | 原则 | 落地做法 |
|---|---|---|
| U1 | **不为设计而设计** | 所有控件用系统原生；不自定义滚动条、菜单、按钮外观 |
| U2 | **语义色，零硬编码** | 全工程禁止出现 `#RRGGBB`；一律 `.labelColor` / `.secondaryLabelColor` / `.controlAccentColor` |
| U3 | **密度克制** | 默认行高 24pt（比访达略紧凑），但提供「紧凑/标准/宽松」三档 |
| U4 | **动效服务于理解** | 动效只用于解释「东西从哪来、到哪去」，时长 0.12–0.3s |
| U5 | **一屏之内完成主要动作** | 复制/移动/删除/重命名/预览均有键盘路径，无需鼠标 |
| U6 | **可预测的破坏性操作** | 删除二次确认，⌥ 跳过；废纸篓可撤销 |
| U7 | **尊重系统设置** | 自动响应深色模式、强调色、减弱动效、增大对比度、字号 |

### 2.5 颜色（全部语义色）

```swift
// 文本
Color(.labelColor)                  // 主文本
Color(.secondaryLabelColor)         // 次文本（大小、日期）
Color(.tertiaryLabelColor)          // 三级文本

// 背景
Color(.windowBackgroundColor)       // 内容区背景
Color(.controlBackgroundColor)      // 列表背景
Color(.unemphasizedSelectedContentBackgroundColor)  // 失焦选中

// 强调
Color(.controlAccentColor)          // 跟随系统强调色

// 其他
Color(.separatorColor)              // 分隔线
Color(nsColor: .systemRed)          // 删除类危险操作
```

**深色/浅色差异交给系统**，我们只保证对比度达标（正文 ≥ 7:1，次要文本 ≥ 4.5:1）。

### 2.6 材质

| 区域 | macOS 26 | macOS 15 |
|---|---|---|
| 侧边栏 | `.glass(.sidebar)`（自动） | `NSVisualEffectView(.sidebar)` |
| 工具栏 | `.windowToolbar`（统一玻璃） | 系统默认 |
| 内容区 | `.background` | `windowBackground` |

**不做手写 blur**——用系统材质，才能在系统更新外观时自动跟随。

### 3.1 三种分栏模式

| 模式 | 布局 | 快捷键 | 典型场景 |
|---|---|---|---|
| **单栏** | 一个 Pane 占满内容区 | `⌘1` | 日常浏览 |
| **横向切分** | 左右两栏，可拖比例 | `⌘2` | 目录 ↔ 目录 对拷 |
| **纵向切分** | 上下两栏，可拖比例 | `⌘3` | 宽文件列表、素材筛选 |

**交互细则：**
- 分隔条拖拽实时更新，双击恢复 50:50
- 只有「当前焦点栏」参与快捷键操作，焦点栏顶部有 2pt 强调色顶边（非焦点栏为分割线）
- `⌘⌥← / →` 切换焦点栏；`⌃⇥` 为备选方案
- 每个 Pane 独立持有：路径、导航历史（后退/前进）、视图模式、排序/整理方式、选择集、滚动位置、过滤词
- 切换布局时上述状态**全部保留**（这是超过 QSpace 的细节）

### 3.2 四种视图模式（每个 Pane 独立）

| 模式 | 快捷键 | 规格 |
|---|---|---|
| **图标** | 工具栏（⌘1–3 已让给切分模式） | 网格 96pt，标签在下，支持缩略图/预览图，可缩放 ⌘+/⌘- |
| **列表** | — | 多列：名称、大小、种类、修改日期、标签；列可显示/隐藏/排序/拖动 |
| **分栏（列视图）** | — | 多列级联，每列一个层级；⌘⌥↑ 在列视图中打开父级 |
| **画廊** | — | 大预览卡 + 右侧文件列表；适合图片/视频素材 |

> 注：视图模式按**文件夹**记忆（`viewOptions.db`），可继承（子文件夹继承父级设置，除非显式覆盖）。可选「始终以图标方式打开」。

## 4. 侧边栏

### 4.1 分组结构

| 分组 | 内容 | 可配置 |
|---|---|---|
| **书签** | 用户自定义书签（支持分组嵌套、拖拽排序、从访达拖入） | ✅ |
| **位置** | 主目录、桌面、文稿、下载、影片、音乐、图片、应用程序、实用工具、/Volumes、网络 | ✅（勾选显示项） |
| **标签** | Finder 标签颜色（红橙黄绿蓝紫灰）+ 「所有标签…」 | ✅ |
| **服务器** | 设置中配置的 SMB/AFP/WebDAV 服务器，带连接状态灯 | ✅ |

### 4.2 交互

- 单击：在当前焦点栏打开
- `⌘` 单击：在新标签页打开
- `⌥` 单击：在对侧栏打开
- 右键：见 §7.4
- 从访达／其他 App 拖入文件夹 → 自动创建书签
- 服务器项右侧：未连接时显示「连接」按钮（hover 出现），已连接显示「推出」
- 支持「折叠/展开」分组（⌘⌥ 点击分组标题可全展开/全折叠）

### 4.3 服务器状态指示

| 状态 | 显示 |
|---|---|
| 已连接 | 🟢 绿点 + 卷名 + 可用空间（hover） |
| 连接中 | 🟡 转圈 |
| 未连接 | ⚪ 灰点，文字为次要色 |
| 失败 | 🔴 红点 + 右键查看错误 |

## 8. 快捷键（完整定义）★

## 14. 动效规范

| 场景 | 时长 | 曲线 |
|---|---|---|
| 目录切换（前进） | 0.25s | `.easeOut` |
| 目录切换（后退） | 0.25s | 反向 |
| 悬停高亮 | 0.12s | `.easeOut` |
| 选中变化 | 0.1s | `.easeOut` |
| Sheet / 弹窗 | 0.3s | 系统默认 |
| 分栏布局切换 | 0.28s | 布局 + 内容淡入 |
| 进度条更新 | 0.2s | 线性 |
| 侧边栏展开/折叠 | 0.2s | `.easeInOut` |
| 拖拽预览跟随 | 实时 | — |

**规则**：
- 尊重「系统设置 → 辅助功能 → 显示 → 减弱动态效果」，开启时全部改为 0.1s 淡入
- 尊重「减弱透明度」，开启时材质降级为不透明背景
- 目录切换动画在 >5000 项时自动禁用（性能优先）
